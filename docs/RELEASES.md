# История версий Solo Island

Каждый сохранённый этап имеет тег `v<версия>`. Он открывает исходники на конец этого этапа; отдельные исправления остаются самостоятельными коммитами в основной ветке.

Установщики закреплены тегами `build/v<версия>`. Ссылки ниже указывают на конкретные коммиты сборок, поэтому скачивание старой версии не переключится на новую. Байты DMG и исходные журналы проверенных сборок сохранены.

**Последняя версия — 0.8.2, сборка 17.** Универсальный DMG для Apple Silicon и Intel, macOS 14+. Перед заменой приложения завершите старую версию кнопкой питания в островке.

## Как устроена история

- `solo-island` — актуальные исходники со всеми промежуточными изменениями в исходном порядке.
- `solo-island-builds` — последовательная история установщиков; последняя запись содержит текущую версию для кнопки в README.
- `v0.1.0` … `v0.8.2` — сохранённые этапы исходников.
- `build/v0.2.0` … `build/v0.8.2` — сохранённые установщики. Для 0.1.0 сохранены только исходники.
- Ветки `preview/*` сохраняют исходные предпросмотры и результаты их проверок.

В `build-info.json` каждой сборки поле `source_commit` указывает именно тот коммит, из которого получен DMG. При переносе из предпросмотра поле `promoted_from` сохраняет коммит исходного установщика, а `run_url` — его проверку в GitHub Actions. Тег исходников может также включать последующие изменения документации.

Для 0.8.2 прошли 55 Swift-тестов на macOS, 38 JavaScript-тестов, 8 проверок публикации и нативные проверки интерфейса в macOS 15 на Apple Silicon. В установщике проверены обе архитектуры; сценарии агентов проверены в WebKit на локальных страницах без входа в личные аккаунты.

## Следующие версии

Изменения коммитятся отдельно по смыслу. После успешной сборки и проверки установщика новая версия получает собственные теги `v<версия>` и `build/v<версия>`, а таблица выше — новую строку. Существующие теги остаются на своих коммитах. Кнопка последней версии продолжает вести в `solo-island-builds`.
