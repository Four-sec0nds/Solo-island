# Claude Code и Codex в Solo Island

Откройте **Агенты** в шапке островка (⌘6), затем **Подключения**.
Нажмите **Подключить** возле уже установленного клиента, перезапустите его и
начните новую задачу. Статус «Ожидаем первую задачу» означает, что настройки
добавлены; «События получены» появляется только после реального события.

Поддерживаются терминальные Claude Code и Codex с lifecycle hooks, включая
`PermissionRequest`. Для Codex нужен клиент, который читает `~/.codex/hooks.json`
и поддерживает этот тип события. Старые версии следует обновить самостоятельно.
Браузерные чаты не подключаются. Совместимость десктопных клиентов зависит от
поддержки тех же hooks в конкретной версии; автоматического захвата окон нет.
Solo Island не устанавливает агенты, не входит в их аккаунты и не читает API-ключи.

## Что видно

- Начало задачи запускает счётчик ЧЧ:ММ; `Stop` останавливает его. Новая задача
  начинает отсчёт заново. Разные клиенты и сессии учитываются отдельно.
- Во время работы видны клиент, проект и последнее имя инструмента. Счётчик
  измеряет время задачи, включая ожидание решения, а не расход токенов/CPU.
- Запрос разрешения показывает проект, инструмент и полный `tool_input`.
  **Разрешить один раз** возвращает `allow` именно этому запросу, **Отклонить** —
  `deny`. Настройки постоянных разрешений не меняются.
- **В клиенте** возвращает запрос в штатное окно подтверждения. То же происходит,
  если Island закрыт, перестал отвечать или истекли две минуты ожидания.
- Подтверждения инструментов не заменяют диалоги уточнений и списки планов:
  ответы на произвольные вопросы агента пока нужно давать в самом клиенте.
- Системные/корпоративные ограничения на hooks могут запретить подключение.
  При отсутствии событий Island не выдаёт вымышленный статус подключения.

Выход процесса клиента останавливает отсчёт, даже если `Stop` не пришёл.
Если процесс остался, но событий нет больше часа, статус меняется на
«Нет свежего статуса»: Island не угадывает состояние клиента.
Активности и время не восстанавливаются после перезапуска Island.

## Изменения и локальные данные

Кнопка подключения объединяет наши command hooks с существующими JSON-настройками:
`~/.claude/settings.json` или `~/.codex/hooks.json`. Если доступны переменные
окружения приложения `CLAUDE_CONFIG_DIR` / `CODEX_HOME`, используются эти каталоги.
Остальные настройки и чужие hooks сохраняются; некорректный JSON не перезаписывается.
Кнопка отключения удаляет только точное совпадение команды Solo Island.
Перед изменением существующий файл сохраняется с правами 0600 в
`~/Library/Application Support/SoloIsland/AgentBridge/` (каталог 0700).

Встроенный подписанный локально `SoloBridge` копируется туда же. Никакие Python,
Node, сервер или сетевой порт для подключения не нужны. Обмен идёт через
приватные каталоги 0700 и файлы 0600. Запросы имеют случайный ID, ограниченный срок
и ID текущего запуска приложения; повторные и просроченные ответы отклоняются.
Символические ссылки в runtime и общедоступные файлы не принимаются.

Тексты запросов и транскрипты не сохраняются. Полный ввод инструмента временно
хранится только для запроса разрешения и удаляется после ответа/истечения срока;
обычные события содержат лишь данные статуса. Недоставленные файлы прошлого
запуска очищаются при следующем запуске. История сессий хранится только в памяти.
Резервные копии настроек остаются на Mac и могут содержать ваши настройки;
вручную удалить их можно после проверки подключения.

## Протокол и проверки

Использованы публичные спецификации, код интеграции написан для Solo Island:

- [Codex hooks и схемы PermissionRequest](https://github.com/openai/codex/tree/05c08d76552371400d273d4539c2a116d6340755/codex-rs/hooks/schema/generated).
- [Codex: обнаружение hooks.json](https://github.com/openai/codex/blob/05c08d76552371400d273d4539c2a116d6340755/codex-rs/hooks/src/engine/discovery.rs).
- [Claude Agent SDK: типы hook input/output](https://github.com/anthropics/claude-agent-sdk-python/blob/2146f9d8985513053e904b13200c8f744b36785a/src/claude_agent_sdk/types.py).

Тесты проверяют отсчёт сессии, несколько параллельных запросов, сохранность
конфигурации, права файлов, подменённые/повторные ответы, истечение срока и
закрытие приложения. Нативная проверка macOS отправляет синтетические события
через настоящий mailbox, нажимает настоящие кнопки SwiftUI и проверяет точный
JSON-ответ. Она не входит в реальные аккаунты Claude/Codex и не запускает команды
инструментов: скриншоты и проверочные запросы явно демонстрационные.
