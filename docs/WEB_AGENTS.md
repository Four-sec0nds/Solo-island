# Веб-агенты

В **Агенты → Подключения → Веб** откройте Claude или ChatGPT/Codex. Войдите на
сайте сервиса и начните запрос. Веб-страница открывается отдельным окном нормального
размера; в Island появляются источник, статус и время работы. Сессии подписаны «веб».

Если сайт блокирует встроенный вход, используйте расширение внешнего браузера.
Нельзя перенести cookies или авторизацию из Safari/Chrome в WebKit автоматически.

## Chrome, Edge, Brave

1. Запустите Island и нажмите **Агенты → Подключения → Браузер → Подключить браузер**.
2. В `chrome://extensions` нужного браузера включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**, выберите открытую приложением
   папку `BrowserExtension` и подтвердите подключение в браузере.
4. Обновите вкладки `claude.ai` / `chatgpt.com` и начните новый запрос.

Это установка локального расширения вне магазина. Само приложение не может
включить расширение без действий пользователя в браузере. Для Safari в этой
версии предусмотрено отдельное веб-окно Island; внешние вкладки Safari не наблюдаются.
Удалить расширение можно на странице управления расширениями браузера.

Подключение регистрирует только `app.solo.island.json` в каталогах NativeMessagingHosts
поддерживаемых браузеров, копирует свой helper и папку расширения в
`~/Library/Application Support/SoloIsland/AgentBridge/`. Остальные настройки
браузера не изменяются. Обмен локальный: стандартный ввод/вывод Native Messaging,
без TCP-сервера, внешнего API, API-ключа или фонового браузерного аккаунта.

## Какие данные и статусы передаются

Разрешённая схема содержит ровно четыре поля: провайдер, домен, случайный UUID
сеанса и состояние (`start`, `working`, `finished`, `interrupted`). Принимаются
только домены Claude и ChatGPT с согласованным провайдером. Расширение имеет
разрешение Native Messaging и запускается только на этих двух сайтах.
ID расширения закреплён публичным ключом в manifest; локальный host разрешает
только этот origin. Ключ manifest публичный и не является API-ключом.

Наблюдатель запускается до скриптов сайта и отслеживает жизненный цикл уже
выполняемых страницей запросов Claude/ChatGPT, завершение потока ответа и поля
статуса задач Codex. Кнопки отправки/остановки остаются дополнительным сигналом.
Наблюдатель не создаёт собственных запросов к API и не читает тела запросов,
cookies, поля паролей и токены. Тексты переписки не анализируются, не копируются
и не передаются в Island. Исходные ответы, объекты и байты возвращаются сайту
без изменения; у задач читаются только ID и перечисленные поля статуса.

Поля задач сверены с официальным клиентом OpenAI Codex:
[`task_status_display.latest_turn_status_display.turn_status` и `current_assistant_turn.turn_status`](https://github.com/openai/codex/blob/48524f337a84b570f0c2453ca43ec9a1a29375c0/codex-rs/cloud-tasks-client/src/http.rs).
В мост передаются только четыре поля; ID задач и адреса бесед остаются на странице.

Вкладка/окно должны оставаться открытыми. Изменения интерфейса и маршрутов сайта, ограничения
фоновых вкладок и отсутствие доступных странице полей статуса могут ограничить
наблюдение. Это не подключение к закрытому серверному API: работа
облачного агента после закрытия страницы не отслеживается. Если поток статусов
пропал, через две минуты счётчик останавливается с неопределённым статусом.
Веб-запрос, у которого не появились признаки генерации за 15 секунд, помечается
прерванным. Время до подключения/после перезапуска Island не восстанавливается.

Браузерное подключение не создаёт кнопок разрешения инструментов: настоящие
подтверждения остаются у поддерживаемых терминальных клиентов через hooks.
Расширение не нажимает кнопки сайта и не отправляет запросы от имени пользователя.

Автотесты используют полный скрипт наблюдателя, локальные DOM-сценарии,
настоящие WebKit fetch/Response/ReadableStream, поля задач Codex, строгую схему
событий и нативный обмен WebKit/Native Messaging. Они не входят в реальные аккаунты и
не являются проверкой всех текущих вариантов интерфейса Claude/ChatGPT/Codex.

В строке подключения веб-окна виден результат установки наблюдателя.
Для обновления ранее установленного расширения снова нажмите «Подключить браузер»,
перезагрузите расширение на странице управления расширениями и обновите вкладки.
