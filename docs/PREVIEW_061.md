# Предпросмотр 0.6.1

Исходники обновления, ещё не проверенные в нативной macOS-сборке.
Публичная ветка и установщик 0.5.4 не изменены.

## Что изменилось относительно 0.6.0

- Левая панель удалена. Пять разделов находятся в нижнем доке.
  Настройки, булавка и полное завершение — справа от него.
- Плеер занимает всю ширину. Управление расположено рядом с названием
  и обложкой, перемотка — под ними. Длинные данные и ошибки прокручиваются.
- Кольцо фокуса находится слева, задача и пауза — справа. Время только ЧЧ:ММ.
- У камеры остаются маленькие индикаторы музыки/фокуса. При отсутствии
  обоих состояний всё скрывается. Наведение на боковые индикаторы раскрывает
  основную панель; после ухода она сворачивается.
- Для музыки отображается настоящая обложка либо иконка выбранного сервиса.
  Три полоски показывают состояние воспроизведения, а не анализ аудио.
  На паузе, при Reduce Motion и во время сна дисплея движение остановлено.
- Таймер показывает значок с прогрессом и ЧЧ:ММ. При одновременной музыке
  возле времени остаётся меньший индикатор воспроизведения.
- Цвета сохранены. Данные и музыкальные веб-сессии не мигрируют и не удаляются.

## Проверки

В Linux прошли синтаксический разбор всех SwiftUI/AppKit-файлов, 31 тест ядра,
8 тестов упаковки и 5 тестов веб-плеера. Это не нативная компиляция SwiftUI.

В сценарий проверки на macOS добавлены проверки настоящего мини-окна,
совместной работы таймера/музыки, паузы, положения относительно камеры,
пассивности окна и раскрытия при наведении после смены Space.
Они ещё не выполнены. Новый установщик и снимки ещё не сформированы.

Сборка на Mac: `bash scripts/setup-mac.sh` из корня распакованных исходников.
Это путь для разработки; он требует Homebrew и Apple Command Line Tools.
Готовый установщик после успешной сборки: `dist/SoloIsland.dmg`.

Для облачной сборки подготовлен триггер `preview/**`. Такая ветка получает
артефакт GitHub Actions и сохраняет установщик, журнал и отдельные снимки
в собственной папке `.preview-build`. Видео не публикуются. Ветка
`solo-island-builds` не изменяется.
Основная ветка, её кнопка скачивания и старая сборка остаются прежними.
Пользователь разрешил отдельную временную ветку для сборки установщика.
