# Проверка безопасности и приватности

Дата: 28 октября 2026 года. Проверялся публичный репозиторий Solo Island и установщики macOS.

## Что проверено

- Доступная история обеих веток Git целиком. Первичный проход: 58 коммитов, 331 уникальный объект файлов, включая 15 версий DMG.
- Исходники, workflow, скрипты упаковки, журналы сборок, снимки и их метаданные. DMG распакованы для проверки состава, текстовых ресурсов и строк в бинарных файлах.
- Автоматический поиск через detect-secrets 1.5.0 и отдельные шаблоны ключей OpenAI, GitHub, AWS, Slack, Google, приватных ключей и паролей в URL. Значения кандидатов в отчёт не записывались.
- Ручная проверка запуска процессов, удаления файлов, сетевых запросов, WebKit-моста и сохранения буфера обмена.

## Результат

Подтверждённых секретов в проверенных файлах и истории не обнаружено. 45 срабатываний сканера — идентификаторы коммитов и закреплённые ревизии зависимостей; ещё одно совпадение с адресом e-mail находилось внутри сжатых данных PNG. Пользовательские задачи, буфер, cookies, базы авторизации, ключи и сертификаты подписи в установщиках не обнаружены. Метаданные PNG содержали размеры изображения, без GPS, имени владельца и серийных номеров камеры.

По согласованию с владельцем имя и обычный e-mail автора заменены в истории веток на Four-sec0nds и адрес GitHub noreply. История исходников, код приложения и байты установщиков сохранены; ссылки `source_commit` в статусах сборок обновлены на соответствующие новые коммиты. Уже скачанные копии и сохранённые GitHub страницы старых коммитов такая замена не стирает.

Компоненты GitHub Actions закреплены по точным SHA. В `.gitignore` добавлены локальные файлы окружения, секреты, приватные ключи и данные приложения. Публикация по-прежнему использует явный список установщика и PNG-снимков; ролики, GIF и архивы кадров не возвращаются в Git.

## Проверенные свойства приложения

- Запуск медиамодуля и «Быстрых команд» передаёт аргументы напрямую, без shell-интерполяции пользовательского ввода.
- Веб-мост принимает метаданные только с хостов выбранного плеера. Поля паролей, cookies и токены авторизации он не считывает; сетевые адреса плееров используют HTTPS.
- Удаление изображения с полки ограничено собственными копиями в папке Clipboard. Обычные файлы пользователя не удаляются.
- Буфер с маркерами ConcealedType, TransientType и AutoGeneratedType пропускается. Обычный скопированный текст без таких маркеров сохраняется в истории, даже если пользователь считает его конфиденциальным.

Задачи и история буфера хранятся локально без отдельного шифрования; веб-сессии находятся в хранилище WebKit приложения. DMG подписан ad-hoc и пока не нотарифицирован Apple. Это проверка кода и содержимого поставки, а не гарантия отсутствия любых уязвимостей в macOS, WebKit, музыкальных сервисах или медиамодуле.

Проверки публикации артефактов и JavaScript-моста: 9 тестов прошли. Прямая ссылка на DMG возвращает HTTP 200, скачанные байты совпадают с опубликованной SHA-256. Исполняемый код приложения в этом обновлении не менялся.
