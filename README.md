# Solo Island

Нативный Dynamic Island для Mac: музыка, собственные задачи, фокусировка, файловая полка и быстрые действия. Интерфейс на русском. Swift / SwiftUI / AppKit, macOS 14+, Apple Silicon (сборка arm64 по умолчанию). На MacBook Air M4 используйте установленную macOS 15 или новее.

**Текущий статус:** исходники первой версии. В Linux выполнены тесты `IslandCore` и синтаксическая проверка Swift-файлов. Полная сборка AppKit/SwiftUI и работа приложения на Mac ещё не проверены. Готового `.app` в репозитории до macOS-сборки нет.

## Запуск на Mac

Homebrew у вас уже установлен. В терминале перейдите в папку с этим README и выполните:

```bash
bash scripts/setup-mac.sh
```

Скрипт установит `media-control` через Homebrew, запустит тесты, соберёт приложение и откроет его. Понадобятся Apple Command Line Tools. Если скрипт попросит установить их:

```bash
xcode-select --install
```

Дождитесь окончания установки и повторите `bash scripts/setup-mac.sh`. Полный Xcode не обязателен.

Альтернатива — открыть `Собрать и запустить.command` в Finder. Результат сборки остаётся в той же папке проекта:

- `dist/SoloIsland.app` — приложение; его можно перенести в `/Applications`.
- `dist/SoloIsland-macOS.zip` — архив приложения.

Приложение не показывает иконку в Dock. Островок находится у выреза камеры; меню управления — значок капсулы в строке меню. Наведите курсор на боковые части островка, чтобы раскрыть его. Кнопка булавки закрепляет раскрытый вид. Без выреза островок размещается по центру верхнего края основного экрана.

Сборка подписывается локально ad-hoc. Это не нотарифицированный релиз Apple. Скрипт не отключает Gatekeeper, TLS и другие проверки.

## Что реализовано

- Активный системный медиаплеер: обложка, трек, исполнитель, пауза, предыдущий/следующий трек, шкала позиции при наличии данных.
- Плавное раскрытие/сворачивание, компактная анимация, закрепление, поддержка Reduce Motion, присутствие поверх полноэкранных окон.
- Индикация изменения громкости и смены активного аудиоустройства.
- Последние 5 файлов, скопированных в Finder, плюс добавление перетаскиванием и через диалог. Открытие, перенос в другие приложения, показ в Finder, удаление с полки.
- Собственный таск-менеджер: задачи, сроки, редактирование, напоминания, списки «Сегодня», «Предстоящие», «Выполненные». Просроченные задачи остаются в «Сегодня».
- Фокусировка по выбранной задаче: 15/25/45/60/90 минут, пауза, продолжение, завершение сессии или задачи, учёт времени. Таймер сохраняется между перезапусками.
- Уведомления задач: начать фокус, отложить на 10 минут, завершить. Для разрешения нажмите кнопку в задачах или настройках.
- Быстрые действия: приложения, папки и системные «Быстрые команды».
- Настройка ширины, скруглений, длительности анимации и акцентного цвета, в том числе по обложке.

Батарея, мониторинг системы, жесты и интеграция с календарём не включены.

## Музыка и совместимость

Используется [media-control](https://github.com/ungive/media-control), установленный Homebrew. Это сторонний проект, использующий приватный MediaRemote; обновление macOS может нарушить совместимость. В приложение не копируются ни его код, ни исполняемые файлы.

```bash
brew install media-control
media-control get
media-control toggle-play-pause
```

Яндекс Музыка в приложении и браузерах — основные целевые сценарии **для проверки на Mac**, а не уже подтверждённая совместимость. Источник должен публиковать медиасеанс в macOS, как для системного Пункта управления. Приложение отображает один активный системный источник; ручного выбора среди всех вкладок и приложений пока нет. Если источник не отдаёт метаданные/длительность, отсутствующие поля и перемотка скрываются. Наличие длительности не гарантирует, что конкретный источник выполнит seek: ошибки показываются в интерфейсе.

При ошибке откройте настройки островка → «Переподключить». Повторный запуск помощника выполняется явно, без бесконечных автоматических перезапусков. Запуск внешних команд передаёт аргументы напрямую, без shell-интерполяции.

## «Не беспокоить»

Публичного API для произвольного переключения Focus у стороннего macOS-приложения нет. Используется поддерживаемая пользователем автоматизация через приложение «Быстрые команды»:

1. Создайте команду `Solo Focus On`: действие «Установить фокусирование» → «Не беспокоить» → включить до выключения.
2. Создайте `Solo Focus Off`: то же действие → выключить.
3. Укажите эти два имени в настройках Solo Island.
4. В запущенной фокус-сессии нажмите «Включить „Не беспокоить“»; при первом запуске macOS может запросить разрешение на выполнение команды.

Включение выполняется по кнопке. При завершении сессии приложение запускает указанную команду выключения, если оно само запускало включение. Перед выходом предупреждает об активной автоматизации. При принудительном завершении процесса выключите режим вручную через Пункт управления. Состояние Focus, изменённое другими приложениями, не отслеживается.

## Данные и файловая полка

`~/Library/Application Support/SoloIsland/state.json`

Задачи, настройки, ссылки на файлы, действия и фокус сохраняются локально атомарной записью. Сервер и аккаунт не нужны. При ошибке чтения исходный файл не перезаписывается. Для резервного копирования достаточно закрыть приложение и скопировать эту папку.

Полка хранит ссылки на оригиналы, без загрузки или копирования содержимого. При перемещении/удалении оригинала потребуется добавить файл снова. Пять мест общие для скопированных и вручную добавленных файлов. Удаление с полки не удаляет файл. Отслеживается буфер с файловыми URL — текст, картинки в виде байтов и файлы, скопированные до запуска приложения, автоматически не подхватываются. Такие файлы можно добавить перетаскиванием. Индикация наушников срабатывает при смене активного аудиовыхода, не при каждом Bluetooth-подключении.

## Разработка и проверки

```bash
swift test
bash scripts/build.sh
```

Пакет без сторонних Swift-зависимостей. `IslandCore` и его тесты работают также в Linux; приложение собирается только с macOS SDK. Используйте существующий checkout: каждая облачная задача уже изолирована; дополнительный Git worktree не требуется.

Чек-лист реальной проверки приложения: [docs/MAC_SMOKE_TEST.md](docs/MAC_SMOKE_TEST.md).

GitHub Actions `.github/workflows/macos.yml` запускает тесты и сборку на macOS и сохраняет ZIP как артефакт **SoloIsland-macOS**. Workflow ещё не запускался в этой сессии. Для сборки на GitHub не требуются сертификаты Apple. Установка `media-control` для работы плеера требуется на целевом Mac отдельно.
